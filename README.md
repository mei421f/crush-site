# 💌 سایت ابراز علاقه

نسخه‌ی بازطراحی‌شده با یه UI مینیمال و شیک، تو یه پنل ادمین خودت اسم و پیام رو وارد می‌کنی.

## چی جدیده؟
- طراحی مینیمال با الهام از اپل: بدون شلوغی، تایپوگرافی تمیز، یه المان امضادار (ارب نرمِ نفس‌کش پشت آیکون‌ها) به‌جای قلب‌های شناور همه‌جا.
- دارک‌مود / لایت‌مود با یادآوری انتخاب کاربر (گوشه بالا-چپ صفحه اصلی).
- فیدبک صوتی سبک روی دکمه‌ها (قابل خاموش‌کردن)، ساخته‌شده با Web Audio بدون فایل اضافه.
- نشانگر مراحل (۱ ← ۲ ← ۳) بالای کارت.
- «کارت خاطره»: در مرحله آخر می‌تونی یه تصویر شیک از سؤال و جواب دانلود کنی.
- پنل ادمین با تب‌بندی (پیام / دیت / تلگرام)، پیش‌نمایش زنده‌ی گوشی‌مانند که همزمان با تایپ آپدیت می‌شه، دکمه «ارسال پیام آزمایشی» برای تست اتصال تلگرام قبل از رانش، و دکمه کپی سریع لینک عمومی سایت.
- کانفتی با پالت رنگی هماهنگ با طراحی به‌جای رنگین‌کمانی.

## ساختار پروژه

```
crush-site/
├── server.js          سرور اکسپرس
├── package.json
├── Procfile           برای Railway
├── data/config.json   جایی که اسم/پیام ذخیره میشه (خودکار ساخته میشه)
└── public/
    ├── index.html      صفحه‌ای که طرف می‌بینه
    ├── admin.html       پنل مدیریت (وارد کردن اسم و پیام)
    ├── style.css
    └── script.js
```

## اجرا روی سیستم خودت (تست قبل از رانش)

```bash
npm install
npm start
```

بعد برو به:
- `http://localhost:3000` → صفحه‌ای که طرف می‌بینه
- `http://localhost:3000/admin.html` → پنل مدیریت (رمز پیش‌فرض: `admin123`)

## رانش روی Railway

1. یه ریپازیتوری گیت‌هاب از این پوشه بساز و پوش کن (یا مستقیم پوشه رو به Railway بدی).
2. برو تو [railway.app](https://railway.app) و پروژه جدید بساز → **Deploy from GitHub repo**.
3. Railway خودش `package.json` رو تشخیص میده و `npm install && npm start` رو اجرا می‌کنه.
4. تو تنظیمات پروژه (**Variables**) این متغیر رو اضافه کن تا رمز پنل ادمین رو خودت انتخاب کنی:
   ```
   ADMIN_PASSWORD=یه-رمز-قوی-انتخاب-کن
   ```
5. بعد از رانش، Railway یه دامنه بهت میده مثل `xxx.up.railway.app`.
   - برو به `xxx.up.railway.app/admin.html` و اسم + پیام رو وارد کن.
   - لینک اصلی `xxx.up.railway.app` رو برای طرف بفرست (دکمه «کپی لینک» تو پنل ادمین هست).

### ⚠️ نکته مهم درباره ذخیره‌سازی
اسم و پیام تو فایل `data/config.json` ذخیره میشه. روی Railway (پلن رایگان/بدون Volume)، هر بار که ری‌دیپلوی کنی این فایل ممکنه ریست بشه. برای جلوگیری از این موضوع:
- بعد از رانش، بلافاصله از پنل ادمین اسم رو وارد کن و دیگه ری‌دیپلوی نکن، **یا**
- از قسمت Railway یه **Volume** به مسیر `/app/data` وصل کن تا دائمی بمونه.

## راه‌اندازی ربات تلگرام (برای پیام خودکار دیت)

وقتی طرف دعوت به دیت رو قبول کنه و روز/ساعت رو بفرسته، سایت خودکار یه پیام برات تو تلگرام می‌فرسته.

1. تو تلگرام برو سراغ [@BotFather](https://t.me/BotFather) و با دستور `/newbot` یه ربات جدید بساز. یه **Bot Token** بهت میده شبیه `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
2. به رباتت یه پیام بده (مثلاً `/start`) تا فعال بشه.
3. برای پیدا کردن **Chat ID** خودت، برو سراغ [@userinfobot](https://t.me/userinfobot) و بهش پیام بده، عددی که برمی‌گردونه Chat ID توئه.
4. برو تو پنل ادمین (`/admin.html`)، تب «تلگرام» رو باز کن، Token و Chat ID رو وارد کن، با دکمه «ارسال پیام آزمایشی» اتصال رو تست کن و بعد ذخیره کن.

به جای پنل ادمین می‌تونی این‌ها رو مستقیم به‌عنوان Environment Variable هم تو Railway ست کنی:
```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```
(این‌ها فقط موقع اولین بار ساخته‌شدن فایل تنظیمات به‌عنوان مقدار پیش‌فرض استفاده میشن؛ بعدش هرچی تو پنل ادمین ذخیره کنی اولویت داره.)

> نکته امنیتی: Bot Token و Chat ID هیچ‌وقت از مسیر عمومی `/api/config` برنمی‌گرده، فقط با رمز ادمین قابل مشاهده‌ست.

## شخصی‌سازی بیشتر
- رنگ‌بندی تو `public/style.css` هست (متغیرهای `--rose`, `--bg`, `--surface` بالای فایل؛ نسخه‌ی دارک‌مود هم زیر `html[data-theme="dark"]`).
- متن‌های پیش‌فرض تو `server.js` (تابع `ensureDataFile`) هست.
- متن‌ها و عنوان بخش «دعوت به دیت» هم از پنل ادمین قابل تغییره.
