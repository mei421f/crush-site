# 💌 سایت ابراز علاقه

یه سایت ساده و شیک برای ابراز علاقه به کسی، با یه پنل ادمین که خودت اسم و پیام رو ازش وارد می‌کنی.

## ساختار پروژه

```
crush-site/
├── server.js          سرور اکسپرس
├── package.json
├── Procfile           برای Railway
├── data/config.json   جایی که اسم/پیام ذخیره میشه (خودکار ساخته میشه)
└── public/
    ├── index.html      صفحه‌ای که طرف می‌بینه
    ├── admin.html       پنل مدیریت (وارد کردن اسم و پیام)
    ├── style.css
    └── script.js
```

## اجرا روی سیستم خودت (تست قبل از رانش)

```bash
npm install
npm start
```

بعد برو به:
- `http://localhost:3000` → صفحه‌ای که طرف می‌بینه
- `http://localhost:3000/admin.html` → پنل مدیریت (رمز پیش‌فرض: `admin123`)

## رانش روی Railway

1. یه ریپازیتوری گیت‌هاب از این پوشه بساز و پوش کن (یا مستقیم پوشه رو به Railway بدی).
2. برو تو [railway.app](https://railway.app) و پروژه جدید بساز → **Deploy from GitHub repo**.
3. Railway خودش `package.json` رو تشخیص میده و `npm install && npm start` رو اجرا می‌کنه.
4. تو تنظیمات پروژه (**Variables**) این متغیر رو اضافه کن تا رمز پنل ادمین رو خودت انتخاب کنی:
   ```
   ADMIN_PASSWORD=یه-رمز-قوی-انتخاب-کن
   ```
5. بعد از رانش، Railway یه دامنه بهت میده مثل `xxx.up.railway.app`.
   - برو به `xxx.up.railway.app/admin.html` و اسم + پیام رو وارد کن.
   - لینک اصلی `xxx.up.railway.app` رو برای طرف بفرست.

### ⚠️ نکته مهم درباره ذخیره‌سازی
اسم و پیام تو فایل `data/config.json` ذخیره میشه. روی Railway (پلن رایگان/بدون Volume)، هر بار که ری‌دیپلوی کنی این فایل ممکنه ریست بشه. برای جلوگیری از این موضوع:
- بعد از رانش، بلافاصله از پنل ادمین اسم رو وارد کن و دیگه ری‌دیپلوی نکن، **یا**
- از قسمت Railway یه **Volume** به مسیر `/app/data` وصل کن تا دائمی بمونه.

## شخصی‌سازی بیشتر
- رنگ‌بندی و گرادینت‌ها تو `public/style.css` هست، راحت عوض کن.
- ایموجی‌های قلب تو `public/script.js` (متغیر `heartEmojis`) قابل تغییره.
- متن‌های پیش‌فرض تو `server.js` (تابع `ensureDataFile`) هست.
